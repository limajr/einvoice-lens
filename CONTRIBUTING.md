# Contributing

Start with the README and public roadmap. Use JDK 21 and run `./mvnw -Pproduction verify`
before submitting changes. Keep contributions small and explain the user-visible change
and relevant validation. Conventional Commit messages are preferred.

Use only synthetic invoices or official samples whose redistribution terms permit use.
Removing a name alone does not anonymize an invoice: addresses, account numbers, tax IDs,
references and embedded attachments can identify people or businesses. Prefer a minimal
synthetic reproduction. Never upload real invoice data to issues or pull requests.

Rule explanations must reference the official rule text and applicable rule-bundle
version. Preserve validator messages and add tests for the affected behavior.
