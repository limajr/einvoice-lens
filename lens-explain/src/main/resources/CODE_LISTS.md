# Display code labels

This is a selected display subset, not a validator or a complete code-list distribution.
English names and meanings were checked against the dated OpenPeppol BIS Billing
2025-Q4 publication. German labels are project-authored translations, not official
German code-list text. Unknown values stay visible as raw codes; display labels never
establish code validity or a particular national VAT percentage.

Sources (accessed 28 October 2026):
- UNCL1001, D.16B: https://docs.peppol.eu/poacc/billing/3.0/2025-Q4/codelist/UNCL1001-inv/
- UNCL1001 credit notes, D.16B: https://docs.peppol.eu/poacc/billing/3.0/2025-Q4/codelist/UNCL1001-cn/
- UNCL4461, D.16B: https://docs.peppol.eu/poacc/billing/3.0/2025-Q4/codelist/UNCL4461/
- UNCL5305 subset, D.16B: https://docs.peppol.eu/poacc/billing/3.0/2025-Q4/codelist/UNCL5305/
- UNECE Rec20 revision 11e, including Rec21 codes with X prefix:
  https://docs.peppol.eu/poacc/billing/3.0/2025-Q4/codelist/UNECERec20/

Only short names and project translations are included in code-labels.tsv; descriptions
and complete source pages are not bundled. Unit names are labels rather than grammatical
plural inflections. C62 uses the published synonym “unit”. XPP is Rec21 PP prefixed with X.
